# Bibata Modern Ice Right

Cursor theme: **Bibata Modern Ice Right**

The cursor theme is included in this repository under:

```text
themes/Bibata-Modern-Ice-Right/
```

To install it:

```bash
cp -r themes/Bibata-Modern-Ice-Right ~/.icons/
```

Then select **Bibata-Modern-Ice-Right** as the cursor theme in KDE System Settings.
