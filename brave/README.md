# Brave Browser

## Browser Theme

[Catppuccin Chrome Theme](https://chromewebstore.google.com/detail/catppuccin-chrome-theme-m/bkkmolkhemgaeaeggcmfbghljjjoofoh)

* Flavor: **Mocha**
* Used for the Brave browser UI.

## Extensions

### Stylus

[Stylus](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne)

For Catppuccin userstyles:

* [Catppuccin Userstyles — Usage / Setup](https://userstyles.catppuccin.com/getting-started/usage/)
* [Catppuccin Userstyles Customizer](https://catppuccin-userstyles-customizer.uncenter.dev/)

I used the **@ucenter customizer** with:

* Light flavor: **Latte**
* Dark flavor: **Mocha**
* Accent color: **Mauve**

The generated stylesheet was imported into Stylus.
