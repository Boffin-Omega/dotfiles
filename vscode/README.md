# VS Code

My VS Code user settings are stored in `settings.json`.

## Setup

Install VS Code, then copy the settings file:

```bash
mkdir -p ~/.config/Code/User
cp settings.json ~/.config/Code/User/settings.json
```

Restart VS Code if it was already running.

## Extensions

Install the following extensions:

```text
catppuccin.catppuccin-vsc
catppuccin.catppuccin-vsc-icons
zakudriver.nyan-mode
```

Or install them from the terminal:

```bash
code --install-extension catppuccin.catppuccin-vsc
code --install-extension catppuccin.catppuccin-vsc-icons
code --install-extension zakudriver.nyan-mode
```
